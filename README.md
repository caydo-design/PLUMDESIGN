# Plum

The all-in-one travel platform for businesses, travel agents, and consumers.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Tech Stack

- Next.js 16 + TypeScript
- Tailwind CSS 4
- Fraunces + DM Sans (Google Fonts)
- Lucide React icons
